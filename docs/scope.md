# 범위

## In

- 웹/서버 기반 프로젝트의 실행 테스트
- 기능적 결함 탐지(실행 중 발견되는 버그, 깨진 흐름)
- 사용성/UX 컨벤션 정합성 평가(근거를 동반한 비평)
- 선언된 목적·비전과 실제 구현의 내적 정합성 검토

## Out

- 코드 자동 수정 (발견·보고까지만 한다)
- 실제 인증기관 절차 대행
- 요구사항의 사업적 타당성 판단
- 자체 이슈 트래킹 기능 (docket/GitHub Issues에 위임)

## 과잉의 판별 기준

새 기능을 Momos에 넣을지 판단할 때: *"이 능력을 처음 쓰는 제3의 소비자가 같은 자리에서 같은 재구현을 하게 되는가?"* — 그렇다면 이 리포의 몫이다. 특정 소비자만의 도메인 지식이 있어야 쓸 수 있는 것이라면 범위 밖이다.

(Later 항목은 이 리포의 비공개 백로그에서 관리한다 — 이 문서는 확정된 것만 다룬다.)
