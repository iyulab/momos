상태: 이 문서는 현재 구현을 기술한다.

# 용어집

| 용어 | 뜻 |
|---|---|
| Host | 프로젝트 등록·신청서 접수·결과서 저장을 담당하는 중앙 서비스 |
| Worker | 실행 환경에서 에이전트를 구동해 검사를 수행하는 실행 노드 |
| Console | Host API의 클라이언트인 관리자 UI |
| 프로젝트 선언 | 대상 프로젝트의 목적·비전·역할·범위·경계 선언. Host의 Projects 엔티티에 등록 |
| 검사 신청서 | 매 실행마다 제출하는 가벼운 검사 요청 |
| 검사 결과서 | 검사 신청서에 대응하는 산출물(발견·근거·판정) |
| 비침습성 | 대상 리포에 어떤 파일도 요구하지 않고 작동하는 성질 |
| 근거 기반 비평 | 리서치나 명확한 증거를 동반한 지적. 근거 없으면 침묵 |
| Computer Use | 화면을 보고 마우스·키보드를 직접 조작하는 에이전트 능력 |
| MCP | Model Context Protocol — 에이전트와 도구 간 표준 호출 프로토콜 |
| 분석 요청 | 프로젝트 모델을 만들라는 요청. 검사 신청서와 같은 큐를 쓰고 종류(`Analysis`)로 구별된다 |
| 프로젝트 모델 | 한 커밋 시점의 프로젝트 설계 이해 — 구성 요소·관계·패턴·결정·의도·흐름·불변식과 그것을 뒷받침하는 진술, 목차, 분석 범위. 분석마다 새 버전이 생긴다 |
| 흐름(flow) | 코드 안에서 요청·작업이 실제로 지나가는 순서 있는 단계. 단계마다 무슨 일이 일어나는지 말하는 진술을 가진다 |
| 불변식(invariant) | 코드가 계속 참이라고 기대는 것(계약·데이터 소유권·보안·동시성 등). 대상 구성 요소와 근거 진술을 가진다 |
| 목차(outline) | 딥 리포트의 장 구성. 분석이 프로젝트에 맞게 장을 정하고, 렌더러는 그대로 배치만 한다. 장 제목·목적은 주장이 아니다 |
| 분석 범위(coverage) | 분석이 읽은 것, 읽지 않은 것과 그 이유, 분석 중 폐기한 제안의 수. `unknowns.md`의 재료 |
| 진술(claim) | 프로젝트 모델의 한 문장. 안정된 키, 등급, 근거, 신뢰도(`High`·`Medium`·`Low`), 판정 상태를 갖는다 |
| 진술 등급 | `Fact`(코드 근거), `History`(커밋·PR·이슈 근거), `Assessment`(다른 진술에 대한 해석 — 재현된 지적이 붙기 전까지 신뢰도 `Low`) |
| 진술 출처(origin) | `Deterministic`(결정적 추출기가 읽은 것) 또는 `Synthesized`(분석의 언어 모델 패스가 제안하고, 분석한 커밋에서 근거 검사를 통과한 것) |
| 근거(evidence) | 진술을 뒷받침하는 출처 — 코드 위치, 커밋, PR, 이슈, 재현된 지적, 또는 해석 대상인 다른 진술 |
| 교정(correction) | 진술에 대한 개발자의 판정(`Confirmed`·`Disputed`·`Corrected`). 진술을 지우거나 고치지 않고 그 옆에 기록된다 |
| `unrecorded` | 이유가 기록되지 않은 결정의 근거 값. Momos는 그럴듯한 이유를 지어내지 않고 빈칸을 드러낸다 |
| 딥 리포트 | 최신 프로젝트 모델을 렌더링한 마크다운 문서 트리(`index.md`가 요약, `unknowns.md`가 이 리포트가 모르는 것) |
| 검진(checkup) | 한 프로젝트를 여러 검사 프로그램으로 한 번에 살피는 단위. 프로그램마다 요청을 큐에 올리고, 모두 끝나면 결과지 하나를 낸다. 종합 점수는 없다 |
| 검사 프로그램(exam program) | 검진이 실행할 수 있는 검사의 종류(`design-analysis` 등). 검진에 포함되지 않은 프로그램은 결과지에 「포함되지 않음」으로 적힌다 |
| 검사 실행(exam run) | 한 검진 안에서 한 검사 프로그램의 실행. 큐의 요청 하나에 대응하고 `Pending`에서 시작해 `Completed`·`Partial`·`NotRun` 중 하나로 끝나며, 온전히 끝나지 않았으면 사유를 갖는다 |
| 증분 분석 | 이전 모델 버전에서 바뀐 부분만 다시 분석하는 것. **아직 구현되지 않았다** — 지금은 매 분석이 전체를 새로 추출한다 |
