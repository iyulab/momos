# 확장 지점

## 실행 환경

Worker는 새로운 실행 환경(예: 데스크톱 GUI)을 지원하도록 확장될 수 있으나, 지금은 웹/서버 지원만 구현하며 그 확장을 위한 추상화 레이어를 미리 만들지 않는다(D-05 — Computer Use 크로스플랫폼 검증 이후 재검토). 확장 시에도 대상 리포에 어떤 파일도 요구하지 않는다는 원칙(비침습성)은 유지된다.

## 도구

에이전트가 오케스트레이션하는 도구(정적 분석, 스크립트, 테스트 도구, Computer Use)는 MCP(Model Context Protocol) 표준으로 노출된다. 새 도구를 추가할 때도 이 표준을 따른다 — 자체 프로토콜을 만들지 않는다.

## 검사 능력

Momos가 다루는 능력(현재: 기능적 결함, 사용성/UX 정합성)은 앞으로 늘어날 수 있다. 새 능력을 추가할 자격은 "이미 있는 실행 환경/코드에서 실제로 반복 관찰되는 필요"에서 나온다 — 단일 사용 사례만으로 선제적으로 추가하지 않는다.
